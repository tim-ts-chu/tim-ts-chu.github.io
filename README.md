# Personal Website

This is my personal website hosted on GitHub Pages. The website showcases my professional information, projects, and contact details.

## Features

- Responsive design that works on all devices
- Clean and modern UI
- Sections for About, Projects, Skills, and Contact
- Easy to customize and maintain

## How to Use

1. Clone this repository
2. Edit the `index.html` file to add your personal information
3. Customize the styles in `styles.css`
4. Add your own images to the `images` folder
5. Deploy to GitHub Pages by:
   - Going to your repository settings
   - Scrolling down to "GitHub Pages" section
   - Selecting the branch you want to deploy (usually `main` or `master`)
   - Saving the changes

## Customization

- Update the profile picture in the `images` folder
- Modify the content in `index.html`
- Adjust colors and styles in `styles.css`
- Add your own projects and skills
